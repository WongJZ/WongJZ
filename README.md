### Project Description

This project is a web-based platform designed to help users discover street vendors in Penang, catering to both local food lovers and tourists. The platform bridges the gap between street vendors and food enthusiasts by offering a user-friendly interface with features that make it easy to explore the city's street food culture. It features real-time tracking capabilities (optional feature) to show vendor locations dynamically and incorporates a review system (optional feature) for users to share their experiences. The primary goal is to enhance the street food discovery process in Penang and support small businesses.

---

### Key Features

* **Intuitive Web-Based Platform:** User-friendly interface for easy navigation.
* **Location-Based Vendor Discovery:** Find vendors based on current location or searched area.
* **Vendor Location Update Feature:** Allows registered vendors to update their location.
* **Google Map API Integration:** Displays vendors on a map and provides directions.
* **Multilingual Support:** Caters to both locals and tourists.
* **Advanced Search and Filter Options:** Search by cuisine, location, ratings, etc.
* **Vendor Profiles and Notifications:** Detailed vendor information and user alerts.
* **Social Media Sharing:** Share vendor findings on social platforms.
* **(Optional) Real-Time Location Tracking:** Dynamically track vendor movements.
* **(Optional) User Reviews and Personalized Recommendations:** Rate vendors and get suggestions.
